# Boxi CS community health files

Boxi CS builds open, reproducible explanations for computer science.

The organization separates reusable engine code, public teaching scenes, public documentation, and private course or assessment assets. Contributions should include a runnable example, verification evidence, licensing information, and an accessible fallback when the change adds a visual artifact.

Public repositories:

- [`cs-explain`](https://github.com/boxi-cs/cs-explain) — engine and trace contract
- [`cs-scenes`](https://github.com/boxi-cs/cs-scenes) — reproducible explanation scenes
- [`cs-explain-site`](https://github.com/boxi-cs/cs-explain-site) — public documentation and demos
